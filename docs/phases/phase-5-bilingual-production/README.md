# Phase 5: লিগ্যাল নোটিশ ইঞ্জিন, ট্যাম্পার-প্রুফ সিকিউরিটি ও প্রোডাকশন ডেপ্লয়মেন্ট

## ১. সারসংক্ষেপ
Phase 5 হলো **Smart AI Legal Automation Platform**-এর চূড়ান্ত কমার্শিয়াল ও প্রোডাকশন সংস্করণ। এই পর্যায়ে প্ল্যাটফর্মটি শুধুমাত্র চুক্তি সম্পাদনেই সীমাবদ্ধ নয়, বরং চুক্তির পরবর্তী বিরোধ মীমাংসা, আইনি নোটিশ প্রদান, দলিলের ক্রিপ্টোগ্রাফিক সত্যতা নিশ্চিতকরণ (Anti-tamper SHA-256) এবং যেকোনো ক্লাউড সার্ভারে এক ক্লিকে ডেপ্লয় করার পূর্ণাঙ্গ প্যাকেজ সরবরাহ করে।

## ২. নতুন ফিচার ও আর্কিটেকচার

### ক. স্বয়ংক্রিয় লিগ্যাল নোটিশ জেনারেটর (Notice Engine)
ভাড়ার চুক্তি বা যেকোনো বাণিজ্যিক সম্পর্কের ভিত্তিতে তিনটি বিশেষায়িত আইনি নোটিশ তৈরি করার সুবিধা:
1. **বাসা / দোকান ছাড়ার আইনি নোটিশ (Vacate Notice):** নির্ধারিত সময়সীমা (যেমন: ৩০/৬০ দিন) উল্লেখপূর্বক আইনানুগ প্রাঙ্গণ প্রত্যর্পণ পত্র।
2. **চুক্তি নবায়ন ও শর্ত প্রস্তাবনা পত্র (Renewal Letter):** মেয়াদান্তে নতুন শর্ত ও ভাড়ার পরিমাণ উল্লেখপূর্বক চুক্তি নবায়ন চিঠি।
3. **বকেয়া ভাড়া ও পাওনা নিষ্পত্তির তাগিদপত্র (Demand Notice):** বকেয়া পরিশোধ ও আইনানুগ উচ্ছেদ সতর্কবার্তা সম্বলিত নোটিশ।
- **API Endpoint:** `POST /api/tools/generate-notice`
- **UI ইন্টিগ্রেশন:** সরাসরি প্রিভিউতে নোটিশ ইনজেক্ট করা অথবা এক ক্লিকে ক্লিপবোর্ডে কপি করার সুবিধা।

### খ. ট্যাম্পার-প্রুফ SHA-256 ক্রিপ্টোগ্রাফিক সুরক্ষা (Cryptographic Integrity)
- দলিলের টেক্সট ও শর্তাবলির গাণিতিক হ্যাশ (`SHA-256`) স্বয়ংক্রিয়ভাবে তৈরি হয়।
- দলিলের যেকোনো একটি বর্ণ বা সংখ্যাও পরিবর্তন করা হলে হ্যাশ পরিবর্তন শনাক্ত হয় এবং সিস্টেম লাল সতর্কবার্তা দেয়: `সতর্কতা: দলিলটি বিকৃত বা পরিবর্তিত (TAMPERED / MODIFIED)`।
- অবিকৃত থাকলে সবুজ সার্টিফিকেট প্রদর্শন করে: `দলিলটি ১০০% অবিকৃত ও খাঁটি (AUTHENTIC & UN-TAMPERED)`।
- **API Endpoints:**
  - `POST /api/tools/generate-hash`
  - `POST /api/tools/verify-hash`

### গ. বহুমুখী ওয়াটারমার্ক সিস্টেম (Dynamic Watermarking)
- দলিলে "খসড়া" (DRAFT COPY) অথবা "গোপনীয়" (CONFIDENTIAL) ওয়াটারমার্ক এক ক্লিকে টগল করা যায়।
- অন-স্ক্রিন প্রিভিউ এবং ব্রাউজার/PDF প্রিন্টিংয়ের ক্ষেত্রেও ওয়াটারমার্ক নিখুঁতভাবে রেন্ডার হয় (`@media print` সাপোর্টেড)।
- **API Endpoint:** `POST /api/tools/apply-watermark`

### ঘ. ক্লাউড ডেপ্লয়মেন্ট প্যাকেজ (Dockerized Production Ready)
- `Dockerfile`: Python 3.11-slim, Chromium headless ও ফন্ট ডিপেন্ডেন্সিসহ লাইটওয়েট প্রোডাকশন ইমেজ।
- `docker-compose.yml`: পোর্ট ৮০৮০/৮০০০ ম্যাপিং এবং SQLite ডাটাবেস পারসিস্টেন্সের জন্য ভলিউম মাউন্ট (`contracts_data`)।
- `.dockerignore`: অপ্রয়োজনীয় ক্যাশ ও টেস্টিং ফাইল ফিল্টারিং।

## ৩. API এন্ডপয়েন্ট রেফারেন্স (Phase 5)

| Endpoint | Method | বিবরণ |
|---|---|---|
| `/api/tools/generate-notice` | `POST` | উচ্ছেদ নোটিশ, নবায়ন চিঠি বা বকেয়া তাগিদপত্র জেনারেট করে |
| `/api/tools/generate-hash` | `POST` | দলিলের কনটেন্টের ক্রিপ্টোগ্রাফিক SHA-256 ফিঙ্গারপ্রিন্ট তৈরি করে |
| `/api/tools/verify-hash` | `POST` | রেফারেন্স হ্যাশের সাথে বর্তমান দলিলের প্রমাণিকতা যাচাই করে |
| `/api/tools/apply-watermark` | `POST` | HTML দলিলের ভেতরে ড্রাফট বা কনফিডেন্সিয়াল ওয়াটারমার্ক ইনজেক্ট করে |

## ৪. ডেপ্লয়মেন্ট গাইড (Deployment Instructions)

### Docker এর মাধ্যমে রান করা:
```bash
# প্রজেক্ট রুটে যান
cd legal-ai-platform

# ডকার ইমেজ বিল্ড ও রান করুন
docker compose up --build -d

# কন্টেইনার স্ট্যাটাস দেখুন
docker compose ps
```
ব্রাউজারে ওপেন করুন: `http://localhost:8000`

### লোকাল মেশিনে রান করা:
```bash
# ব্যাকএন্ড শুরু
cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
