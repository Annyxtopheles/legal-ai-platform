# Phase 1: MVP Architecture & Core Engine

## ১. সারসংক্ষেপ
Phase 1-এ প্ল্যাটফর্মটির মৌলিক ব্যাকএন্ড ও ফ্রন্টএন্ড আর্কিটেকচার প্রতিষ্ঠা করা হয়েছে। এতে ব্যবহারকারীর তথ্য ইনপুটের মাধ্যমে স্বয়ংক্রিয়ভাবে প্রফেশনাল চুক্তিপত্র তৈরি এবং PDF আকারে ডাউনলোডের মূল ভিত্তি রচিত হয়।

## ২. মূল উপাদানসমূহ
- **FastAPI Backend:** উচ্চগতির পাইথন ব্যাকএন্ড ও REST API এন্ডপয়েন্ট।
- **Jinja2 Template Engine:** ভ্যালিডেটেড আইনি টেমপ্লেট থেকে নির্ভুল HTML পেপার রেন্ডারিং।
- **Google Gemini AI Integration:** কাস্টম শর্তাবলি পলিশ করা (Refine Clause) এবং জটিল আইনি ধারা সহজ ভাষায় ব্যাখ্যা (Plain Language Explainer)।
- **Headless Chrome PDF Engine:** বাংলা ফন্ট ও প্রিন্ট মার্জিন অক্ষুণ্ণ রেখে ১০০% নিখুঁত PDF তৈরি।

## ৩. প্রাথমিক ৩টি চুক্তিপত্র
1. বাড়ি / ফ্ল্যাট / দোকান ভাড়ার চুক্তিপত্র (Tenancy Agreement)
2. নন-ডিসক্লোজার চুক্তি (Non-Disclosure Agreement - NDA)
3. ফ্রিল্যান্সার ও ক্লায়েন্ট সেবা চুক্তিপত্র (Freelance Contract)
